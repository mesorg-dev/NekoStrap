Лаунчер, который выглядит как надо и помнит, где ты играл. Чёрно-белый,
быстрый, один exe без установки — и с фишками, которых нет у конкурентов.

## 🔥 Самые имбовые фишки

**🔄 Возвращение на тот же сервер.** Вылетел с крутой катки? В истории
сохраняется JobId сервера — один клик «На тот же сервер», и ты падаешь
к тем же людям. Плюс «сервер-хоп» на случайный сервер того же плейса.

**🪟 Живое жидкое стекло.** Панели блюрят обои ровно под собой, текст
остаётся идеально чётким. А обои — любые: фото и даже гифки, с настройкой
блюра и затемнения отдельно для фона и отдельно для панелей.

**🔊 Свои звуки интерфейса.** Клик, наведение, переходы, тумблеры —
на каждый звук можно кинуть свой wav и выставить громкость. Движок сам
чистит файлы (стерео→моно, нормализация).

**🎵 Музыка и цветокор прямо в трее.** Плеер папки `Music` (шаффл,
громкость) и цветокоррекция экрана с живыми ползунками и авто-режимом
«только в игре» — без сторонних программ.

**👥 Мультиаккаунты в один клик.** Куки хранятся шифром (DPAPI, только
твой ПК), запуск под выбранным аккаунтом, проверка живости кук, бэкап.

**📊 Знает, где ты был.** Счётчик наигранного по каждой игре, последняя
игра с «Играть снова», гео и пинг текущего сервера как в Shift+F5.

**⚡ Честный портатив.** Не лезет в реестр, живёт в одной папке,
обновляет и откатывает клиент сам, чинит CDN для РФ.

## Все функции

**Главная** — установка/проверка клиента, «Играть» с прогрессом, статус,
статы, последняя игра, карточка сервера (IP, гео, пинг).

**Моды** — файлы из `Mods`, вкл/выкл/удалить, Fleasion с автозапуском.

**FastFlags** — таблица флагов версии, живой поиск, 16 пресетов
(FPS 60/144/240, свет, MSAA, Vulkan…), импорт/экспорт JSON, удаление
по одному и все сразу.

**Версии** — установленные клиенты (активация/удаление/откат), Studio.

**Аккаунты** — добавление по куке, активный для запуска, бэкап/импорт.

**История** — итоги по плейсам, лог заходов, копии PlaceId/ссылок,
открытие плейса на сайте.

**Настройки** — тумблеры применяются сразу, путь Roblox, CDN-фикс,
обои, стекло, звуки.

## Сборка из исходников

Нужны **.NET 8 SDK** и **Windows**.

```bash
dotnet restore
dotnet build NekoStrap.sln -c Release
```

Одиночный self-contained exe:

```bash
dotnet publish NekoStrap.Wpf/NekoStrap.Wpf.csproj -c Release -r win-x64 \
  --self-contained true /p:PublishSingleFile=true \
  /p:IncludeNativeLibrariesForSelfExtract=true -o build-wpf
```

Дымовой тест всего UI (без показа окон, код возврата = число провалов):

```bash
dotnet run --project NekoStrap.Smoke -c Release
```

## Релизы

Версия — в `<Version>` (`NekoStrap.Wpf.csproj`). Новый релиз:

```bash
git tag v1.1.0 && git push origin v1.1.0
```

Workflow соберёт `NekoStrap.exe` и приложит к GitHub-релизу — лаунчеры
подхватят его сами. Соглашение для апдейтера: тег `vX.Y.Z`, в ассетах
один `.exe` (лучше с `win-x64` в имени).

## Структура

```
NekoStrap/
├── NekoStrap.sln
├── NekoStrap.Wpf/        # приложение: окно, страницы, тема, трей
│   ├── Theme/Theme.xaml  # палитра, стили, иконки
│   ├── Pages/            # 8 разделов + диалоги
│   ├── Glass.cs          # жидкое стекло (блюр обоев под панелями)
│   ├── GifPlayer.cs      # анимированные GIF-обои
│   └── MainWindow.*      # хром окна + весь бэкенд
├── NekoStrap.Core/       # общая логика без UI (библиотека):
│   ├── Roblox/           #   установщик, запуск, версии, моды, флаги,
│   │                     #   аккаунты, сессии, Discord, CDN, апдейтер
│   ├── Media/            #   музыка (NAudio)
│   ├── Utils/            #   звуки интерфейса
│   ├── Display/          #   цветокоррекция (Magnification API)
│   └── Assets/           #   встроенные wav
├── NekoStrap.Smoke/      # дымовой тест UI
└── .github/workflows/    # CI: сборка релизного exe по тегу
```

## Данные

Всё лежит в `%LocalAppData%\NekoStrap` (или в своей папке, если задан
свой путь Roblox): `config.json`, версии клиента, `Mods/`, `Music/`,
флаги, аккаунты (DPAPI-шифр), история. Реестр лаунчер не трогает.
