## Главная

- Установка и проверка клиента Roblox, кнопка **«Играть»** с прогрессом.
- Статус (`Готов к запуску` / работа / ошибка) + версии лаунчера и клиента.
- Статы: модов установлено, FastFlags активно, часов в Roblox.
- Последняя игра (название, PlaceId, когда был, сколько наиграно) + **«Играть снова»**.
- Карточка сервера во время игры: IP, гео (город/страна), пинг как в Shift+F5.
- **Поиск игр**: строка на Главной, живой API Roblox (omni-search) — название,
  автор, сколько сейчас играют и иконка; двойной клик открывает плейс.
- **Чистый запуск**: кнопка «Чисто» у последней игры — стартует без модов
  и без флагов (снимок состояния, всё возвращается после выхода). Если Roblox
  упал с ненулевым кодом — лаунчер сам предлагает перезапуск чисто и пишет код.
- Авто-профили на игру (см. «Моды» и «FastFlags»): по PlaceId подставляются
  свой набор модов и свой профиль флагов.

## Моды

- **Профили модов** — инстансы набора файлов («пак текстур», «офф-звук»):
  создание, дублирование, удаление и переключение в один клик. Каждый профиль —
  своя папка `ModProfiles\<имя>`, старая папка `Mods` переезжает в `Default`.
- Смена профиля сначала откатывает прошлые правки (manifest + бэкапы в
  `ModState\<version>`) и только потом накладывает новый набор — клиент
  всегда чистый, без кашы из двух наборов. Применение — при установке клиента
  и перед каждым запуском.
- **Быстрая замена** лёгких файлов: звук смерти (`content\sounds\ouch.ogg`),
  шрифты (`content\fonts`), курсор (`content\textures\Cursors\KeyboardMouse`),
  текстуры UI и пола. Выбрал файл — он лёг в активный профиль; путь слота
  правится самому (конец с расширением = один файл, без расширения = папка),
  «Сброс» убирает слот и клиент возвращается к ванили.
- **Экспорт/импорт профиля в zip**: корень архива = зеркало клиента. Отдал
  другу — он импортирует и получает ровно тот же набор (имя подбирается,
  чтобы не перетереть существующее).
- **Авто-профиль на игру**: привязка «моды → игра» по PlaceId (карточка
  «Авто-профили» на вкладке). Запустил плейс — подставился нужный набор,
  отвязка — в один клик; последняя запущенная игра подхватывается сразу.
- Список файлов активного профиля (путь = место в клиенте).
- Вкл/выкл (`.disabled`), удаление, добавление файлов.
- Fleasion: статус, скачивание с GitHub, автозапуск рядом с игрой, кнопка папки.

## FastFlags

- Таблица флагов активной версии клиента: добавление, удаление (кнопка/Delete).
- Кнопка **«Удалить все»** (с подтверждением, в файл — по «Сохранить»).
- Живой поиск, импорт/экспорт JSON, кнопка «Сохранить».
- 16 кликабельных пресетов (повторный клик убирает флаг): FPS 60/144/240,
  свет Future/ShadowMap/Voxel, без блюма, без пост-эффектов, MSAA x4/x8,
  детали далеко, без травы, дальний зум, без DPI-скейла, Vulkan, пинг в лог.
- **Профили**: именованные наборы флагов («FPS», «Красиво») — сохранить текущий,
  применить в один клик, удалить. Хранятся в `flag_profiles.json`.
- **Авто-профиль на игру**: привязка «флаги → игра» по PlaceId (карточка
  «Авто-профили»). Перед запуском нужного плейса профиль применяется сам.

## Версии

- Установленные версии клиента: GUID, размер, статус (активна/предыдущая).
- Активация версии (= откат на предыдущую), удаление (активную нельзя).
- Roblox Studio: установка, запуск, статус.
- **Параллельная загрузка клиента**: пакеты качаются нитками (в настройках —
  сколько потоков), с ретраями и возобновлением с места обрыва.
- **Фоновое обновление Roblox** (тумблер в настройках, по умолчанию выключено):
  пока лаунчер открыт, свежая версия тихо ставится в фоне, к запуску всё готово.
- **Проверка целостности клиента**: сверка файлов с базовым снимком версии —
  пустые/пропавшие/обрезанные, с учётом модов. Кнопка **«Ремонт»** переставляет
  клиент с нуля (моды применяются заново). Снимок пишется при установке.

## История

- Итоги по плейсам: наиграно, последний раз, PlaceId. Сортировка
  «Недавние / По времени». Удаление и очистка (по одной и всей).
- Лог заходов: игра, PlaceId, JobId, время захода, длительность, IP.
- Кнопка **«★ В избранное»** — кидает выбранную игру на Главную.
- **«На тот же сервер»** (PlaceId+JobId), «На плейс», копия PlaceId,
  копия ссылки, открыть плейс на сайте, удаление заходов, очистка лога.
- Двойной клик по заходу = перезайти на тот же сервер.

## Настройки

- Тумблеры применяются сразу, без кнопки «сохранить»: закрытие при запуске,
  Discord RPC (+ свой App ID, свой ключ большой картинки, плейс-кнопка
  «Открыть игру»), **фоновое обновление клиента** (по умолчанию выкл.),
  звуки, проверка обновлений, FPS-анлокер
  (+ значение), трей при сворачивании/закрытии, уведомления, счётчик времени,
  фиксы Roblox (трей/автозапуск через `appStorage.json`).
- **Потоки загрузки** (1–16) — сколько пакетов качать одновременно.
- Путь установки Roblox (портативный) + кнопка обзора.
- Кнопка «Сохранить настройки» — для текстовых полей.
- CDN-фикс для РФ (hosts, нужен админ): включить/откатить + статус.
- Фон: фото/гифки (включая webp), размытие, затемнение, выбор/сброс.
- Стекло: прозрачные панели, непрозрачность, блюр подложки,
  затемнение элементов.
- **Внешний вид**: шрифты заголовков/интерфейса/моно (Unbounded, Inter,
  JetBrains Mono и системные), цвета трёх уровней текста (палитра + hex),
  всё живьём без перезапуска, кнопка сброса.
- Звуки интерфейса: свой wav на каждый из 6 звуков (клик, наведение,
  переход, закрытие, тумблер вкл/выкл) + громкость каждому. Подойдёт
  любой wav — движок чистит сам.

## Трей

- Один экземпляр приложения. Сворачивание/закрытие в трей, иконка `N`.
- Меню: Открыть, Играть, информация о сервере, перезайти на тот же сервер,
  сервер-хоп (другой сервер того же плейса), музыка, цветокоррекция, выход.
- Всплывашки о сервере (отключаются).

## Музыка (меню трея)

- Папка `Music` (mp3/wav/m4a/aac/wma/flac): играть/пауза, следующий,
  предыдущий, стоп, шаффл, громче/тише, список треков (12 + счётчик),
  открыть папку.

## Цветокоррекция (меню трея)

- Насыщенность/яркость/контраст/температура через Magnification API
  (на видеокарте, без инъекций — бан невозможен).
- Пресеты: Стандарт, Кино, Ярко, Чёрно-белое.
- Режим «только когда игра активна», окно-тюнер с живыми ползунками поверх игры.

## О программе

- Версия лаунчера, ссылки GitHub/Discord/Telegram.
- Обновления: проверка релизов, чейнджлог, скачивание с прогрессом
  и установка с перезапуском.

## Окно и внешний вид

- Встроенные шрифты: Unbounded (заголовки), Inter (интерфейс),
  JetBrains Mono (технические строки). Своя иконка `N`.
- Безрамочное окно, drag/даблклик/ресайз/снап — нативные.
- Сайдбар: 7 разделов, активный подсвечен полосой.
- Жидкое стекло: панели блюрят обои ровно под собой (GPU).
- Тёмные скроллбары, тёмные поля ввода, клавиатура (Tab/стрелки/Enter/Delete).
- Геометрия окна запоминается. Свои wav-ресурсы вшиты в exe.
