# NekoStrap — кастомный лаунчер Roblox

[![Release](https://img.shields.io/github/v/release/mesorg-dev/NekoStrap?style=flat-square)](https://github.com/mesorg-dev/NekoStrap/releases)
![.NET 8](https://img.shields.io/badge/.NET-8-512BD4?style=flat-square)
![WPF](https://img.shields.io/badge/UI-WPF-000000?style=flat-square)

![License](https://img.shields.io/badge/license-MIT-green?style=flat-square)

Один exe на .NET 8 и WPF: ставит и обновляет клиент Roblox, держит моды и
FastFlags в профилях, помнит, где ты играл, и показывает это в Discord.
Без установки, без реестра, без аккаунта — запустил и работает.

Telegram: https://t.me/mesorgdev

## Скачать

[NekoStrap.exe из последнего релиза](https://github.com/mesorg-dev/NekoStrap/releases)
— Windows 10/11 x64, ничего ставить не надо. Лаунчер обновляется сам:
увидел новую версию → предложил поставить из раздела «О программе».

## Возможности

**Главная** — установка и проверка клиента, «Играть» с прогрессом, статус
и статы, поиск игр, последняя игра с «Играть снова», карточка сервера
(IP, гео, пинг — как в Shift+F5), избранные плейсы, чистый запуск.

**Моды** — профили (инстансы набора файлов, пак текстур на один клик),
быстрая замена звука смерти/шрифтов/курсора/текстур, вкл/выкл/удаление,
экспорт и импорт профиля в zip, авто-профиль под игру, Fleasion
с автозапуском. Смена профиля сначала откатывает прошлые правки
(manifest + бэкапы) и только потом накладывает новый набор.

**FastFlags** — таблица флагов активной версии, живой поиск, 16 пресетов
(FPS 60/144/240, свет, MSAA, Vulkan…), именованные профили, импорт/экспорт
JSON, перетаскивание строк, авто-профиль под игру.

**Версии** — установленные клиенты: активация, откат на предыдущую,
удаление, Roblox Studio. Параллельная загрузка с возобновлением, фоновое
обновление, проверка целостности и ремонт.

**История** — наиграно по каждому плейсу, лог заходов (PlaceId, JobId,
время, длительность, IP), избранное. «На тот же сервер» и сервер-хоп
на случайный сервер того же плейса.

**Discord** — статус с названием игры, сервером, иконкой и временем сессии;
кнопка «Открыть игру» на страницу плейса или вход к другу на твой сервер.
Название, сервер, иконка, время и кнопки настраиваются по отдельности.

**Трей, музыка, цветокор** — сворачивание в трей, меню с перезаходом
и сервер-хопом; плеер папки `Music` (шаффл, громкость); цветокоррекция
экрана через Magnification API с пресетами и режимом «только в игре».

**Внешний вид** — жидкое стекло (панели блюрят обои под собой), GIF-обои
с блюром и затемнением, свои шрифты и цвета текста живьём, свои wav
на каждый звук интерфейса с громкостью, тема без перезапуска.

**Система** — локализация RU/EN переключается на лету, CDN-фикс для РФ
(hosts, нужен админ), автообновление лаунчера с GitHub, портативность:
всё в одной папке, реестр не трогается.

**Чат лаунчера** — две комнаты («Все» и «Сервер»), личные сообщения
внутри комнаты, оверлей поверх игры.

## Чат лаунчера

Две комнаты и личные сообщения внутри комнаты:

- **«Все»** — общий чат всех, кто подключён из лаунчера, работает всегда.
- **«Сервер»** — чат текущего сервера Roblox: видят только те, кто на этом
  же сервере и запускает NekoStrap. Комната = PlaceId + JobId сессии,
  поднимается при входе в игру и рвётся при выходе.
- ЛС доставляются только внутри одной комнаты и только между игроками
  NekoStrap.
- Страница «Чат»: вкл/выкл, ЛС, оверлей при входе в игру. Тумблер
  оверлея продублирован в трее.
- Летающий оверлей поверх игры: перетаскивается зажатием шапки,
  сворачивается в полоску, «×» прячет без разрыва соединения. Работает
  в оконном и безрамочном режиме.

## Сборка из исходников

Нужны .NET 8 SDK и Windows.

```bash
dotnet restore
dotnet build NekoStrap.sln -c Release
```

Одиночный exe:

```bash
dotnet publish NekoStrap.Wpf/NekoStrap.Wpf.csproj -c Release -r win-x64 `
  --self-contained false /p:PublishSingleFile=true `
  /p:IncludeNativeLibrariesForSelfExtract=true -o build-wpf
```

Дымовой тест всего UI и логики (окна не показываются, код возврата —
число провалов):

```bash
dotnet run --project NekoStrap.Smoke -c Release
```

Сейчас в наборе 41 проверка: установка, моды и их откат, FastFlags,
профили, импорт JSON (в том числе конфликты), zip-импорт/экспорт,
поиск, локализация, настройки.

## Релизы

Версия лежит в `<Version>` (`NekoStrap.Wpf.csproj`). Новый релиз —
тег и пуш:

```bash
git tag v1.3.0 && git push origin v1.3.0
```

Workflow на Windows собирает self-contained exe с версией из тега,
переименовывает в `NekoStrap-vX.Y.Z-win-x64.exe` и создаёт релиз.
Лаунчеры подхватывают его сами: соглашение для апдейтера — тег `vX.Y.Z`,
в ассетах один `.exe` с `win-x64` в имени.

## Структура

```
NekoStrap/
├── NekoStrap.sln
├── NekoStrap.Wpf/        # приложение: окно, страницы, тема, трей, оверлей чата
│   ├── Theme/Theme.xaml  # палитра, стили, иконки
│   ├── Pages/            # 7 разделов + диалоги
│   ├── Lang.cs           # движок локализации (RU/EN)
│   ├── LangStrings.cs    # словари строк
│   ├── Glass.cs          # жидкое стекло (блюр обоев под панелями)
│   ├── GifPlayer.cs      # анимированные GIF-обои
│   ├── ChatOverlayWindow.* # летающий оверлей чата
│   └── MainWindow.*      # хром окна + весь бэкенд
├── NekoStrap.Core/       # общая логика без UI (библиотека):
│   ├── Roblox/           #   установщик, запуск, версии, моды, флаги,
│   │                     #   сессии, Discord, целостность, поиск, чат (WebSocket)
│   ├── Media/            #   музыка (NAudio)
│   ├── Utils/            #   звуки интерфейса
│   ├── Display/          #   цветокоррекция (Magnification API)
│   └── Assets/           #   встроенные wav
├── ChatServer/           # сервер чата — в .gitignore, в репо не публикуется
├── NekoStrap.Smoke/      # дымовой тест UI
└── .github/workflows/    # CI: сборка релизного exe по тегу
```

## Данные

Всё лежит в `%LocalAppData%\NekoStrap` (или в своей папке, если задан
свой путь Roblox): `config.json`, версии клиента, `ModProfiles/` (профили
модов), `ModState/` (бэкапы для отката), `Music/`, флаги, история.
Реестр лаунчер не трогает.
