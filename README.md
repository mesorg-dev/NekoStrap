Лаунчер, который выглядит как надо и помнит, где ты играл. Чёрно-белый,
быстрый, один exe без установки — и с фишками, которых нет у конкурентов.

## 🔥 Самые имбовые фишки

**🔄 Возвращение на тот же сервер.** Вылетел с крутой катки? В истории
сохраняется JobId сервера — один клик «На тот же сервер», и ты падаешь
к тем же людям. Плюс «сервер-хоп» на случайный сервер того же плейса.

**🪟 Живое жидкое стекло.** Панели блюрят обои ровно под собой, текст
остаётся идеально чётким. А обои — любые: фото и даже гифки, с настройкой
блюра и затемнения отдельно для фона и отдельно для панелей. Два режима:
тонированное (тинт + блюр) и чистое (только блюр).

**🔊 Свои звуки интерфейса.** Клик, наведение, переходы, тумблеры —
на каждый звук можно кинуть свой wav и выставить громкость. Движок сам
чистит файлы (стерео→моно, нормализация).

**🎵 Музыка и цветокор прямо в трее.** Плеер папки `Music` (шаффл,
громкость) и цветокоррекция экрана с живыми ползунками и авто-режимом
«только в игре» — без сторонних программ.

**📑 Профили флагов.** Собрал сетап под FPS или под красоту — сохранил
как профиль и переключаешь в один клик. Пресеты внутри тоже есть.

**⭐ Избранное.** Любимые плейсы пинятся на Главную: запуск в один клик,
добавление — кнопкой из Истории.

**🎨 Своя тема.** Шрифты заголовков, интерфейса и моно + цвета текста
(палитра и hex) — меняется живьём, без перезапуска.

**🌍 Русский / English.** Полная локализация интерфейса — переключается
в Настройках, применяется сразу без перезапуска.

**📊 Знает, где ты был.** Счётчик наигранного по каждой игре, последняя
игра с «Играть снова», гео и пинг текущего сервера как в Shift+F5.

**⚡ Честный портатив.** Не лезет в реестр, живёт в одной папке,
обновляет и откатывает клиент сам, чинит CDN для РФ.

## Все функции

**Главная** — установка/проверка клиента, «Играть» с прогрессом, статус,
статы, последняя игра, карточка сервера (IP, гео, пинг).

**Моды** — файлы из `Mods`, вкл/выкл/удалить, Fleasion с автозапуском.

**FastFlags** — таблица флагов версии, живой поиск, 16 пресетов
(FPS 60/144/240, свет, MSAA, Vulkan…), профили, импорт/экспорт JSON.

**Версии** — установленные клиенты (активация/удаление/откат), Studio.

**История** — итоги по плейсам, лог заходов, избранное, копии
PlaceId/ссылок, открытие плейса на сайте.

**Настройки** — тумблеры применяются сразу, язык (RU/EN), путь Roblox,
CDN-фикс, обои, стекло, звуки, шрифты и цвета, чат лаунчера.

**Чат** ⚠️ *в разработке, пока нестабилен* — общий чат роблокс-с��рвера и
ЛС между игроками NekoStrap (подробности ниже).

**О программе** — версия, проверка обновлений, ссылки, лицензия.

## 💬 Чат лаунчера (в разработке)

> ⚠️ **Функция ещё в разработке и пока не работает «из коробки».**
> Чату нужен отдельный сервер, который ты поднимаешь сам — без него
> лаунчер просто не сможет подключиться. Возможности могут меняться.

Как это устроено:

- **Видят друг друга только на одном сервере.** Комната чата = PlaceId +
  JobId текущей сессии: если вы на одном и том же роблокс-сервере —
  вы в одном чате, если на разных — не пересекаетесь вообще.
- **Общий чат сервера + ЛС.** Писать в общий канал может любой в комнате;
  личные сообщения доставляются **только** внутри одной комнаты (на другой
  сервер ЛС не придёт) и только между теми, кто запускает NekoStrap.
- **Только в игре.** Чат поднимается при входе в сессию и рвётся при выходе —
  вне игры общаться нельзя.
- **Настройки → Чат лаунчера:** вкл/выкл чат, вкл/выкл ЛС, летающий
  оверлей при входе в игру, адрес сервера чата, свой ник. Всё это же
  есть в трее: «Оверлей чата при входе в игру» и «Открыть оверлей чата».
- **Летающий оверлей** поверх игры: перетаскивается зажатием шапки,
  сворачивается в полоску кнопкой «—», «×» прячет (чат не рвётся).
  Работает в оконном/безрамочном режиме Roblox.

### Серверная часть: где её взять

Код сервера лежит в папке `ChatServer/` и **намеренно добавлен в
`.gitignore`** — он не публикуется в репозитории (есть только у владельца
лаунчера). Это отдельное консольное приложение на .NET 8 (Kestrel +
WebSocket), без единой NuGet-зависимости.

Локально для разработки:

```bash
dotnet run --project ChatServer          # слушает http://0.0.0.0:8787
# проверка: http://localhost:8787/health  →  {"ok":true,...}
```

В лаунчере укажи адрес `ws://localhost:8787/ws` (Настройки → Чат).

### Как купить сервер и развернуть чат там (пошагово)

Чат-серверу нужен крошечный VPS, работающий 24/7 (1 vCPU / 1 ГБ RAM хватает
с запасом). Пошаговая инструкция — в `ChatServer/README.md`, кратко:

**1. Где купить VPS:**

| Провайдер | Регион | Цена |
|---|---|---|
| [Timeweb](https://timeweb.ru), [Beget](https://beget.com), [Selectel](https://selectel.ru) | РФ, оплата картой/СБП | от ~70–200 ₽/мес |
| [Hetzner](https://hetzner.com) | Европа | от ~€3.5/мес |
| [DigitalOcean](https://digitalocean.com) | США/Европа | от $4/мес |

При заказе: ОС **Ubuntu 22.04/24.04 LTS**, регион ближе к игрокам.

**2. Собрать и залить на сервер:**

```bash
dotnet publish ChatServer -c Release -r linux-x64 --self-contained true -o dist
scp -r dist/* root@ТВ_IP:/opt/neko-chat/
```

**3. Автозапуск (systemd):**

```ini
# /etc/systemd/system/neko-chat.service
[Unit]
Description=NekoStrap ChatServer
After=network.target
[Service]
WorkingDirectory=/opt/neko-chat
ExecStart=/usr/bin/dotnet /opt/neko-chat/NekoStrapChatServer.dll
Restart=always
Environment=NEKO_CHAT_URLS=http://0.0.0.0:8787
[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now neko-chat
```

**4. Открыть порт 8787** в панели провайдера (firewall / security groups)
и в `ufw` (`sudo ufw allow 8787/tcp`). Проверка: `http://IP:8787/health`.

**5. Адрес в лаунчере:** `ws://IP:8787/ws` — впиши его в дефолт
(`ChatServerUrl` в `LauncherConfig`) перед сборкой exe, чтобы он стоял
у всех твоих игроков.

**6. (Опционально) домен + шифрование:** поставь Caddy перед сервером
(`reverse_proxy localhost:8787`) — он сам выпустит TLS-сертификат, и адрес
станет `wss://chat.example.com/ws`. Домен берут у любого регистратора
(~100–300 ₽/год), A-запись → IP сервера.

Протокол (JSON over WebSocket), лимиты (500 символов, 10 сообщений/10 сек,
история 100 сообщений) и полный systemd-разбор — в `ChatServer/README.md`.

## Сборка из исходников

Нужны **.NET 8 SDK** и **Windows**.

```bash
dotnet restore
dotnet build NekoStrap.sln -c Release
```

Одиночный exe:

```bash
dotnet publish NekoStrap.Wpf/NekoStrap.Wpf.csproj -c Release -r win-x64 `
  --self-contained false /p:PublishSingleFile=true `
  /p:IncludeNativeLibrariesForSelfExtract=true -o build-wpf
```

Дымовой тест всего UI (без показа окон, код возврата = число провалов):

```bash
dotnet run --project NekoStrap.Smoke -c Release
```

## Релизы

Версия — в `<Version>` (`NekoStrap.Wpf.csproj`). Новый релиз:

```bash
git tag v1.3.0 && git push origin v1.3.0
```

Workflow соберёт `NekoStrap.exe` и приложит к GitHub-релизу — лаунчеры
подхватят его сами. Соглашение для апдейтера: тег `vX.Y.Z`, в ассетах
один `.exe` (лучше с `win-x64` в имени).

## Структура

```
NekoStrap/
├── NekoStrap.sln
├── NekoStrap.Wpf/        # приложение: окно, страницы, тема, трей, оверлей чата
│   ├── Theme/Theme.xaml  # палитра, стили, иконки
│   ├── Pages/            # 7 разделов + диалоги
│   ├── Lang.cs           # движок локализации (RU/EN)
│   ├── LangStrings.cs    # словари строк
│   ├── Glass.cs          # жидкое стекло (блюр обоев под панелями)
│   ├── GifPlayer.cs      # анимированные GIF-обои
│   ├── ChatOverlayWindow.* # летающий оверлей чата (в разработке)
│   └── MainWindow.*      # хром окна + весь бэкенд
├── NekoStrap.Core/       # общая логика без UI (библиотека):
│   ├── Roblox/           #   установщик, запуск, версии, моды, флаги,
│   │                     #   сессии, Discord, CDN, апдейтер, чат (WebSocket)
│   ├── Media/            #   музыка (NAudio)
│   ├── Utils/            #   звуки интерфейса
│   ├── Display/          #   цветокоррекция (Magnification API)
│   └── Assets/           #   встроенные wav
├── ChatServer/           # ⚠️ сервер чата — В .gitignore, в репо не публикуется
├── NekoStrap.Smoke/      # дымовой тест UI
└── .github/workflows/    # CI: сборка релизного exe по тегу
```

## Данные

Всё лежит в `%LocalAppData%\NekoStrap` (или в своей папке, если задан
свой путь Roblox): `config.json`, версии клиента, `Mods/`, `Music/`,
флаги, история. Реестр лаунчер не трогает.
